# maps/ — spec + provenance convention

Every `<name>.json` is a playable map spec. Every spec MUST carry a
`_notes` field explaining how its terrain was made — a new map
without provenance is a rejected map.

## Three provenance classes

1. **Generated** — `_notes` records the FULL recipe so the bin can be
   rebuilt: tool chain + arguments + seed. Examples:
   - maplab: `synth seed N, <knobs>, verbs(...)` (copy params gives this)
   - genmap chain: `genmap --bowl=... -> simrock -> simwater -> ...`
   - repair: base bin -> `pitfill.py` -> `simsand` -> `simwater`
2. **Ported** — `_notes` says `T1/T2 port` + source. The extracted bin
   is the source of truth; no regen path exists.
3. **Unknown** — `_notes` honestly says `no recorded recipe`. Backfill
   with a recipe when regenerating; don't leave it silent.

## Making a new map (the repeatable path)

- Open `/maplab.html`, dial the synth, use verbs to shape (verbs log
  is the recipe — order matters, `!op` disabled, `op*k` strength,
  `op@x,z` brush strokes).
- `⬇ .bin` downloads the heightmap → drop into `maps/<name>.bin`.
- `copy params` copies the whole recipe — paste it into `_notes` of a
  new `<name>.json` (terrain/heightScale/terrainPreset are already in
  the JSON; add name/mode/bases/spawns).
- `node _tools/mapbake/hillshade.cjs maps/<name>.bin maps/<name>.relief.png`
  regenerates the picker preview.

## Files per map

- `<name>.json` — spec (committed).
- `<name>.bin` — u8 heightmap, `u32 w × u32 h` header (gitignored, ships
  from working tree).
- `<name>.relief.png` — hillshade preview (gitignored, regenerated by
  hillshade.cjs).

## Spec fields

`name`, `mode` (ctf/dm/tdm/headhunt/nuggets/duel), `bots`, `botFill`,
`bases` + `teamSpawns` (CTF only — ignored in other modes), `spawns`
(free circles, all modes), `structures`, `terrain` (bin path),
`heightScale` (relief gain), `tileSize`, `terrainPreset` (0-9 palette),
`fog`/`atmosphere`/`weather`/`sky`, `killY`, `water`, `_notes`.
