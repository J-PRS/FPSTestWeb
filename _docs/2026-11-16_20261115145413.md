Surveyed CS:GO/CS2 `.dem`, Dota 2 replays, deterministic input-replay formats (Klotho/Netick/Partii). Here's what the industry stores vs what we already have:

## We already have the good parts

Magic + formatVersion, `tableHash` (enum-table drift guard — CS2 demos wish they had this), `runSeed`, roster id table, local frames with inputs/mouse deltas, projectile/target event streams, checksum over the tail.

## Worth adding (ranked)

1. **Map/terrain identity** — biggest concrete gap. `FORMAT.md` itself says `room` is the lobby name, *not* the map. A demo can't guarantee it plays on the right terrain. Store `mapName` + `terrain` file + `heightScale`/`tileSize` (or a spec hash). Dota/CS both bind map name in the header.

2. **Tick rate / sim cadence** — every format surveyed stamps it (`tickIntervalMs`, `playback_ticks`). Playback currently assumes the cadence it was built with; a 20Hz recording played under different assumptions drifts subtly.

3. **Roster richness** — we store bare wire ids. CS2 keeps per-player meta (name/team/class). Extend roster rows to `{ id, displayName, team, armorClass }` — enables a correct scoreboard/IFF overlay in replay without wire context. Wire `name` now exists on state, so display names are free.

4. **Source/perspective stamp** — `pov|server` (CS's POV-vs-GOTV split). Our own `CLIP_TRUTH_VS_BEAUTY` doc already calls out that client clips record *beliefs* and server streams record *truth* — a verdict tool needs to know which it's reading. One byte + `serverBuild`.

5. **Score/state timeline** — scoreboard edges (ffaScores/teamScores/held) so replay HUD shows the real score, not a re-derived one. CS2 v3 keeps `rounds.json` + stats snapshots for the same reason.

6. **Chat (public only)** — Dota demos carry all-chat; useful for flavor and disputes. Public channel only — never team/whisper. Optional lane.

7. **Signed match receipt in the footer** — `ResultSigner` already mints signed match records; embedding it makes a demo self-authenticating for leaderboard/dispute claims. Unique-to-us win, cheap.

8. **Periodic stateHash checkpoints** (Partii's pattern) — hash the replayed world every N frames so playback validation can report the *first* divergence tick instead of a vague end-mismatch.

## Don't add

IPs/tokens/hardware fingerprints (agreed, creepy + a leak), team/whisper chat, per-frame full rosters (delta like CS2), or cosmetic VFX state — presentation replays itself.
