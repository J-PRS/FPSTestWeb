# Buzzard — server-owned ambient creature port

2026-11-09. Status: implemented, scenario-tested, uncommitted (rides the
current dirty tree with the Q3 map workstream).

## What it is

The ambient "kettle of buzzards" decor (`AmbientBirds`, client-only flock)
made into a real neutral creature: map `creatures` pops mint it, the
server sims it, the wire carries it, clients render instanced replicas.
Hostile wildlife — orbit, fold-dive, peck — but `scoreless`/`lootless`
fodder, not match entities.

Design intent (rimrock.json `_creatures_notes`): orbit high, fold-dive
the nearest live player, hold a grudge on whoever shot them. Hazards,
not the match.

## Architecture

Same contract as every wire species (rakk/gnat/strifer):

- **Spawn**: `MapSpec.creatures` pop → `CreatureSim` interval tick →
  `creatureSpawn.spawnCrawler` → `SPECIES_FAMILY[speciesFamily(name)].make`
  → `makeSimFlyer(id, pos, uber, seed, 'buzzard')`. Spawn payload carries
  `seed`, `uber`, `species`, `targetId`, `tp`.
- **Step**: shared `stepFlyer` state machine — `orbit → windup → dive →
  climb → orbit`. Edge kinds (`windup`/`pounce`/`bite`) are the wire;
  motion is continuous and replays identically on both ends.
- **Client replica**: `netCrawlers` `WIRE_SPECIES.buzzard` →
  `Buzzard.bindNet` → `bindNetSim` re-makes the sim from the wire
  seed+species → `updateNetSim`/`stepFlyer`. `Buzzard.hitClaim` wired
  through the same loop as every species (`claimDamageMelee`).
- **Damage**: client `takeDamage` → `creatureHit` claim → server
  `CreatureSim.handleHit` → `applyFlyerDamage` (shared) → `kill` or
  `brain.noteHit` (grudge).
- **Bite**: `CreatureBrain.bite` validates the committed target is within
  8m live, then `Room.onBite` → `crawlerBite` → `combat.crawlerAttack`
  pays `biteDamage` server-side. `dep:` targets get gnawed instead.
- **Render**: `buzzardVisual.ts` — instanced swarm parts (2 wings + tail
  fan per bird), soar-dihedral/flap-burst anim, `SWARM_SPECS.buzzard`
  capacity 64 / max 6. `flyers.ts` species entry has `interval: ∞` —
  wire-owned only, never ambient.

## Stats — server row vs client

Both ends read `shared/species.ts`; nothing is duplicated:

| Stat | Value | Source |
|---|---|---|
| family | `fly` | species row |
| speed | 1.25 → ORBIT_SPEED 16.25, DIVE_SPEED 37.5 | row → `makeSimFlyer` tunables |
| orbitR / orbitAlt | 20m / 16m | row → `sp.ORBIT_R/ALT` |
| bite | 20 | row → `biteDamage` → `crawlerAttack` |
| health | 80 (uber ×3.4 = 272) | row → `makeSimFlyer` |
| spawn lift | surface + 16 | `SPECIES_FAMILY.fly.lift` = `sp.ORBIT_ALT` |
| aggro / hit / stun / cd | 85m aggro, 2.4m claw reach, 0.6s stun, 2.5–4.5s dive cd | shared `FLYER_SIM` |

Client constants `BUZZARD_RADIUS = 1` (uber ×1.6) and
`BUZZARD_ORBIT_ALT = 16` are visual/Targetable envelope + ctor spawn
hint only — they match the row but don't drive the sim.

## The grudge (new brain feature)

`creatureBrain.ts`: `noteHit(id, playerId)` records a 6s grudge
(`GRUDGE_S`) and forces the next retarget immediately. `retarget` checks
the grudge before the nearest-player scan — a shot bird turns on its
shooter, not the closest bystander. Wired from `CreatureSim.handleHit`
(non-lethal hits only). Server-only by design: the effect reaches
clients as ordinary retarget edges.

## Fixes that rode along

- `roomFactory.ts`: `creatureSim.attachField(f)` — creatures' `step()`
  early-returned forever on `spec.terrain` rooms (the default-field
  fallback only covered field-less rooms). Map pops were silently dead
  on terrain maps; this enables them.
- `roomStructures.ts`: hullbox `yaw` support (q3conv ports emit
  local-frame min/max + yaw).
- `mapCatalog.ts`: `_q3` flag + GPLv2 dev-only gate (same as `_t2`/`_t1`).
- `combatBlast.ts`: `refuse()` drops routine 'env' far-misses
  (`dist - radius > 15`) — bot spam was generating thousands/min of
  sweep noise.

## Content

`maps/rimrock.json`: `"creatures": { "buzzard": 4 }` — the only map pop
so far. `AmbientBirds` decor stays; the real birds are the sim ones.

## Verification

- `server_bun/tests/scenarios/buzzard.test.ts` — **pass** (1 test, 3
  expects): pops spawn under cap and a shot buzzard holds the grudge on
  the shooter.
- Stat fidelity audit (this report): client and server both resolve
  stats through `makeSimFlyer` + `SPECIES.buzzard`; wire spawn carries
  seed/species so the replica can't drift to rakk defaults.

## Known gaps / not verified

- No client `tsc --noEmit` or vitest run scoped to the new files; the
  dirty tree contains other mid-flight workstreams.
- `_tools/e2e/_buzzwire.ts` headless probe exists (waits for live
  buzzards, screenshots `buzzard-live.png`) — not confirmed run; no GPU
  visual pass on the instanced parts.
- Client `radius` (1.0) vs server flat 1.4 sweep/melee/knock fallback —
  same convention gap every non-totem species has; server is authority.
- Client ctor spawn Y uses `terrain.getHeight`; server uses
  `max(hmHeight, hmChord)` — sub-meter pop on chord-bridged gullies,
  corrected by first wire edge.
- Grudge is brain-layer only; the offline `updateLocalSim` path (gunlab
  preview) won't reproduce it — acceptable, nothing spawns locally.
