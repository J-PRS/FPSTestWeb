# Fog Stack — Full Report

2026-11-09. Survey of every fog/haze/atmosphere layer in the client, the
techniques each uses, how it compares to current cheap-aesthetic practice,
and the ranked gaps.

## 1. Inventory — what renders fog today

### 1.1 Scene-level `THREE.Fog` (linear)

- `client/src/world/scene.ts:53` — `scene.fog = new THREE.Fog(FOG_COLOR,
  FOG_START, FOG_END)`; `FOG_COLOR 0xBBD0E8`, `FOG_START 120`,
  `FOG_END 600` (`client/src/core/config.ts:410-412`).
- Reaches every built-in material (Lambert/Standard) via three's fog
  chunks. Map specs override color/range through `applyMapFog`
  (`client/src/game/net/mapAssets.ts:63-88`): `spec.fog.color` re-tints,
  `distance`→near, `visible`→far; absent resets to engine haze.
- Per-frame `syncFog` (`client/src/game/gameLoop.ts:283-296`) pushes
  `fog.color/near/far` into the terrain uniforms, `FX_FOG` shared uniforms
  (`client/src/world/directionalFog.ts:63-70`), the atmospheric sky
  (`setFogColor`/`setHorizonColor`), and the cube-sky dome
  (`updateCubeSky`, `mapAssets.ts:1019`).

### 1.2 Terrain clipmap shader — the real fog

`client/src/world/terrainShaders.ts` — all four biome branches converge on
the same composite (`:912-921` and siblings at :549, :629, :830):

- **Exp² distance fog** — `terrainFogFactor(dist)` (`:213-216`): natural
  `1-e^-(t²·4)` roll-off with a `*1.05` saturation tail so the clipmap's
  far edge dissolves fully into sky haze (no terrain-colored rim).
- **Height-augmented fog** — `smoothstep(fogStart·0.6, fogEnd·0.7, dist)
  × smoothstep(0.3, 0.8, height)`: tall terrain picks up extra haze with
  distance.
- **Valley mist** — `heightFogAmount(ro, delta, dist)` (`:189-206`):
  exponential height fog **integrated analytically along the view ray**
  (closed-form `(1-e^-kΔy)/(k·rdy)` term handles up/down rays exactly).
  Density peaks at `HF_FLOOR=18`, falls off `HF_K=0.024/m`, extinction
  `HF_D0=0.0024/m` at floor, capped at `HF_CAP=0.80` so haze never soups.
  This is UE5's `ExponentialHeightFog` baseline technique — no raymarching.
- **Edge fade** — `edgeA` dissolves the outer clipmap ring.

The composite: `fogFactor = clamp(dist + heightFog + mist·(1-dist))`,
then `mix(col, fogColor, fogFactor)` → `bloomGuard` → tonemap.

### 1.3 Interiors inherit the same model

`mapAssets.ts:1361-1401` — interior Lambert materials get an
`onBeforeCompile` patch injecting `INTERIOR_FOG_GLSL`: linear haze +
height term (scaled by `uIntHscale`) + `interiorMist` (the same
analytic height-fog integral). Interiors dissolve into the same air as
the terrain outside.

### 1.4 Sky / horizon melt

- `client/src/world/atmosphericSky.ts` — full **single-scattering
  Rayleigh+Mie sky** (wwwtyro/glsl-atmosphere port, `:16-98`): 8-step
  optical-depth march through two scattering layers, mieCoefficient /
  mieDirectionalG uniforms, `horizonColor` uniform for the map-painted
  horizon re-cut (`:144`). `fogColor` uniform is the h=0 seam — must equal
  saturated terrain exactly or the terrain→sky blend breaks (`:22`).
- `updateCubeSky` (`mapAssets.ts:1019-1025`) copies the live fog color
  into the cube-dome's `uFog` — distant scenery melts into sky haze.
- `directionalFog.ts` — `fogTint()` sunward-warm/away-cool tint exists
  and is unit-tested, but is **deliberately not wired**: a
  camera-dependent `scene.fog.color` would swing the sky dome's shared
  horizon band with the camera and break the seamless blend. Directional
  warmth is served by the sky's Mie glow instead (`:6-10`).

### 1.5 Cloud decks — volumetric-looking, zero raymarching

`client/src/world/volumetricClouds.ts` — one dome, **6 stacked 2D noise
dekcs**; the view ray is intersected with N horizontal planes in
`[yMin,yMax]`, each plane an independent noise slice with per-layer
coverage, wind shear (upper decks scroll faster), a sunward-shifted
sample for self-shadowing, and dark-belly→lit-top gradient
(`:16-30`). MAX_DIST 5000, DOME_RADIUS 5000 (past the 4000 sky sphere —
sky writes no depth so the transparent dome composites over it).
Weather intensity per kind rides `AmbientWeather.setWeather`
(`client/src/effects/ambientWeather.ts:33`).

### 1.6 Ground mist cards

`client/src/effects/groundMist.ts` — **9 instanced billboards** in one
`InstancedMesh`, anchored to the lowest sampled terrain spots (mist
physically pools in basins), 16×6m soft glow sprites at opacity 0.065,
slow wander + shared wind drift with the cloud decks, yaw-facing camera.
"Rolling fog banks" trick — no volumetrics.

### 1.7 Fake god rays

`client/src/world/sunShafts.ts` — one additive quad at the sun
position with a procedural radial-streak canvas texture; depth-tested so
terrain occludes it naturally; opacity fades when not looking sunward.
"90% of the read for one draw call" (`:1-10`).

### 1.8 Weather particles

`client/src/effects/ambientWeather.ts` — per-map intensity for ambient
particle kinds (rain/snow/etc.); complements, doesn't replace, fog.

### 1.9 Underwater

`client/src/world/waterSurface.ts:210` — DOM overlay grade, explicitly
not renderer fog.

## 2. Technique assessment vs. cheap-aesthetic practice

| Technique | Us | Field standard | Verdict |
|---|---|---|---|
| Analytic exponential height fog (no march) | ✅ view-ray integral | UE5 `ExponentialHeightFog` baseline; Inigo Quilez analytic-sphere approach | **SOTA for the cost class** |
| Exp² / exp distance falloff | ✅ `1-e^-(t²·4)` + saturation tail | Standard; linear fog looks cheap, exp looks atmospheric | Good |
| Height-augmented fog on tall geometry | ✅ | Common in terrain engines (thickness cue) | Good |
| Single-scatter Rayleigh+Mie sky | ✅ 8-step march | Same family as Preetham/Hosek-Wilkie | Strong |
| Stacked-plane cloud decks, no march | ✅ 6 layers | Stylized-cloud standard trick | Strong |
| Ground mist billboards in basins | ✅ | Classic "fog bank" cheat | Good |
| God rays | ⚠️ sprite only | Radial-blur depth pass is the real one | Accepted cheat, documented |
| **Directional inscatter inside fog medium** | ❌ flat `fogColor` mix | UE5 height fog tints toward sun; "warm haze sunward" is THE cheap-aesthetic signature | **Gap #1** |
| **Animated fog density** | ❌ static analytic mist | 2-3 scrolling noise octaves on density is the standard "alive" upgrade | **Gap #2** |
| Height fog on non-terrain (players/weapons) | ⚠️ interiors yes, entities no | Shared chunk patch or onBeforeCompile | Gap #3 |
| True volumetrics (blue-noise raymarch @¼ res) | ❌ | ~0.1–0.3 ms on discrete GPU; wrong cost class for this art style | Skip |
| Fog meshes / heightfield fog cards | ❌ | Top-down/strategy trick; wrong camera for FPS | Skip |
| Volumetric fog upsampling filters (bicubic/tricubic) | n/a | UE5 niche; irrelevant without a 3D fog volume | n/a |

## 3. The real gaps, ranked by aesthetic-per-cost

### Gap 1 — Directional inscatter in the fog medium — **IMPLEMENTED 2026-11-09 (rimrock only)**

`fogViewColor()` in `terrainShaders.ts` ports `fogTint()` to GLSL;
`spec.fog.dirTint: true` gates it per-map via `terrain.setFogDir()`.
Only `maps/rimrock.json` sets it — other maps unchanged (fogDir=0).
Interiors/entities still flat; tint strengths are the CPU-tuned 0.42/0.18
and may need visual tuning.

### Gap 1b — Distance-gradient fog color — **IMPLEMENTED 2026-11-09 (rimrock only)**

`fogRampColor()` samples up to 6 authored stops (`uniform vec4
fogRamp[6]` + `fogRampN`) keyed by normalized distance
`(dist - fogStart)/(fogEnd - fogStart)` — the FireWatch/COZY technique.
`spec.fog.ramp: [[t, r, g, b], ...]` (sRGB, sorted, ≥2 stops) flows
through `applyMapFog` → `terrain.setFogRamp()`; absent/`<2` stops =
flat `fogColor` as before. Rimrock's authored ramp: pale dust near
(0.85,0.76,0.62) → base (0.78,0.66,0.5) → deep amber far
(0.58,0.46,0.34). Composes under dirTint (ramp supplies base color,
directional tint warms/cools it).

<details><summary>Original Gap 1 analysis (pre-implementation)</summary>

Today the mist term mixes to a **flat `fogColor`**. The single most
recognizable "expensive fog" cue is fog that glows warm toward the sun
and cools away — currently that warmth exists only in the sky dome's
Mie scattering, not in the medium between camera and terrain.

- `directionalFog.ts:fogTint()` already computes exactly this tint
  (sunward `1,0.82,0.55` @ 0.42 strength, away `0.3,0.55,0.92` @ 0.18)
  and is tested — it was shelved because mutating `scene.fog.color`
  swings the dome's shared horizon band.
- The correct wiring is **inside the terrain shader's fog mix**, not
  `scene.fog.color`: pass `sunDir` (the uniform already exists at
  `terrain.ts:264`) + camera dir into the fragment, compute
  `fogTint(base, camDir, sunDir)` per-pixel or per-vertex, mix toward
  that instead of flat `fogColor`. ~10–20 lines of shader; the sky dome
  never sees it. Interiors' `INTERIOR_FOG_GLSL` can take the same two
  varyings later.
- Caveat: per-pixel camera-dir × sun-dir is one `dot()` — cheap. Keep
  the horizontal-only guard from `fogTint` (looking straight up at the
  sun shouldn't whiten the ground haze).

</details>

### Gap 2 — Animated mist density

`heightFogAmount` is static: same valley, same haze, every frame. The
standard upgrade is 2–3 scrolling noise octaves modulating density —
`noised()`/`noise()` helpers already exist in `terrainShaders.ts`
(`:185-187`). Multiply `HF_D0` by a low-frequency scrolling field
(e.g. `0.7 + 0.6·noise(xz·0.002 + t·windDir)`), maybe a second octave for
picket-fence breakup. Cost: ~2 noise evals/px on terrain only — terrain
is already the heaviest shader, so keep it to 2 octaves and consider
gating by `fogFactor > 0` early-out. Instanced ground-mist cards already
drift with the same wind vector — sync the shader drift direction to
`WIND_X/WIND_Z` (`groundMist.ts:19-21`) so banks and haze move together.

### Gap 3 — Height fog on entities

Players, weapons, projectiles, deployables get flat `THREE.Fog`
(120–600 linear) — a distant player doesn't pick up valley mist the
terrain around them does, which reads as a cutout. Options:

- `onBeforeCompile` patch on the shared entity material(s) injecting the
  same height-fog term — the interiors patch (`mapAssets.ts:1361`) is
  the working template; needs `vWorldPos` + camera pos varyings.
- Or accept it: at FOG_END=600 the linear fog already saturates most
  entity silhouettes; the mist only matters in the 120–400 band where
  terrain haze is subtle anyway. **Verify visually before building** —
  this may be a non-problem at current ranges.

### Explicitly skipped

- Raymarched volumetric fog / froxel grids — wrong cost class; the
  stacked decks + mist cards already sell atmosphere.
- Fog meshes — top-down technique, wrong camera.
- Re-wiring `scene.fog.color` per-frame — breaks the sky seam (documented
  in `directionalFog.ts:6-10`); do Gap 1 inside the shader instead.
- Depth-based fog for the viewmodel — viewmodel is inside fog near=120
  anyway; no one sees fog on their own gun.

## 4. Oddities / cleanup notes

- `terrain.ts:264` — `fogStart: 80, fogEnd: 400` initial uniforms vs
  config `FOG_START 120 / FOG_END 600`; `updateFog` (`:720-724`)
  overwrites per frame, so initials are dead values — harmless but
  misleading.
- `directionalFog.ts` `updateDirectionalFog()` is exported but its only
  consumer was the abandoned per-frame tint — if Gap 1 lands, this
  function gets reused inside the shader path (CPU side just supplies
  `sunDir`, already uniform).
- `groundMist` opacity 0.065 × 9 cards is tuned to be subliminal — if
  Gap 2 lands, consider nudging card opacity up slightly since animated
  shader mist will carry more of the read.

## 5. Tribes 2 / Torque reference — how the midair look was actually done

Sources: `tribes2/engine` SVN mirror (`terrain/sky.cc`, `terrain/sky.h`,
`sceneGraph`), Tribes 2 Mod Development Handbook (Bones' mapping
tutorial, fog section), Torque3D `fogStructs.h` docs.

### The T2 model — fog VOLUMES as translucent altitude planes

`Sky` owns up to `MaxFogVolumes` (3) fog volumes, each authored in the
`.mis` as `fogVolumeN = "distance bottomAltitude topAltitude"` plus a
per-volume `color` and a `percentage` blend (`sky.cc:306-314, 337-343`).
Rendering is **not** per-fragment volumetrics: the sky pass computes
`banHeights`/`alphaBan` (`Sky::calcAlphas_Heights`, `sky.cc:742+`) —
horizontal translucent fog planes/quads at each band's altitude, alpha
ramped by camera height inside the band and by distance. Three
non-overlapping bands = a stepped gradient: thick at ground level,
thinning with altitude — "the fog will be at altitude 120 and down, but
there will be multiple steps in how visually obscuring it is" (Bones).

On top of that:

- `TerrainBlock.visibleDistance`/`hazeDistance` — ordinary distance haze
  on terrain (shipped maps: haze 250, vis 1200).
- **Per-volume fog colors** — bands can tint differently (warm low fog,
  cool high fog).
- **Storm fog** — `mStormFogData` animates each volume's `percentage`
  in/out over time with per-volume speed (`sky.cc:86-100, 370-397`);
  `sky.stormFog(percentage, time)` console command. Fog is *weather*,
  not a static setting.
- `mRealFog` — a secondary animated fog mode (max/min/speed).

### Why it read well in midair

Tribes play is spent jetpacking between terrain layers at long sight-
lines. The altitude bands mean climbing literally passes you *through*
strata — each band is a visible horizon line you ascend out of, which
sells vertical scale better than any continuous gradient. And Bones'
cardinal rule — fog color must match the sky's predominant color or the
horizon seams — is the same contract our `atmosphericSky.ts:22` h=0
uniform enforces.

### T3D descendant — exponential height fog

Modern Torque3D replaced the plane bands with `FogData { density,
densityOffset, atmosphereHeight, color }` — exponential fog with a
height falloff, i.e. the same family as our analytic `heightFogAmount`.
The industry converged on what we already have.

### Takeaways for us

- **Our continuous exponential mist is technically superior** to T2's
  three hard bands — smoother, camera-height-aware, ray-integrated.
  What T2 has that we lack is *authored stratification*: discrete
  altitude layers with distinct densities/colors read as "weather
  systems" in a way a single smooth field doesn't.
- **Cheap borrow #1 — banded mist**: our `heightFogAmount` could take a
  second/third Gaussian band at higher altitude (e.g. a thin cirrus
  deck ~150–300m) — still analytic, still ~free, gains the
  climb-through-strata read.
- **Cheap borrow #2 — per-band/per-region color**: T2's per-volume
  colors are the poor-man's directional inscatter. Our Gap 1
  (sunward tint inside the fog mix) is the modern equivalent and
  strictly better — do that first.
- **Borrow #3 — weather coupling**: T2 storm fog animates density over
  time. Our `HF_D0` is a compile-time constant; making it a uniform
  driven by `AmbientWeather`/map spec would let missions author
  "fog rolling in" — pairs naturally with Gap 2's animated noise.
- **Validation**: Bones' warning that engine fog can leave terrain
  texture visible as a wrong-colored haze is exactly our seam problem —
  the h=0 `fogColor` contract already handles it; keep it.

### Additional styles surveyed (2026-11-09, round 2)

- **Distance-gradient fog color** — FireWatch/NoirBear and COZY Weather
  both drive fog color from a 1D ramp sampled by distance (4–5 authored
  stops), not a constant. Near haze light/cool → far haze dense/warm.
  Cheapest big lever left: we already compute `fogFactor`/`dist` per
  pixel; a 4-stop `mix` chain replaces the flat `fogColor` lookup.
  Per-map authorable via `spec.fog` stops.
- **Height-gradient fog color (Fog of Lost Random)** — their Switch-safe
  screen-space fog lerps a *lower* color to an *upper* color by the
  view ray's height through the layer, plus a skybox layer above.
  Direct upgrade path for our `heightFogAmount`: tint the mist term by
  altitude instead of flat `fogColor` — valley floor haze dense/warm,
  thinning to sky-lit air aloft.
- **Stepped fog (COZY "Stepped Fog")** — same height fog but quantized
  into discrete density/color bands. Literally the T2 banded model
  smoothed into one formula; `floor(fogFactor * N) / N` if we ever want
  the graphic-novel look.
- **Fog cards, upgraded** — Magnopus/UE practice: dual panning noise
  textures multiplied into card alpha, per-card world-pos offset so
  cards don't share a pattern, opacity lerp between plain mist and full
  noise, camera-proximity fade. Our `groundMist.ts` has the instancing
  and basin anchoring; these are material/shader upgrades on the same 9
  cards — contained, no new systems.
- **Local fog volumes** — UE Local Fog Volumes / insodimension
  "distance fog bank": bounded volumes of dense noisy fog for specific
  basins/hollows. Analytic version fits our stack: a per-map spec
  (center, radii, density, color) adding another closed-form term to
  `heightFogAmount` — authored pockets of soup without raymarching.
  This is the smooth version of T2's authored bands.
- **Weather-driven fog events** — T2 `stormFog(percentage, time)`;
  our `HF_D0` is a compile-time constant. Making density a uniform
  driven by `AmbientWeather`/map spec gives "fog rolling in" events.
- **Fog receiving light** — UE volumetric fog composites shadowmaps
  (fog darkens in shadow). Cheap approximation exists (reduce inscatter
  where `shadowMask` is low) but our fog is a surface mix, not a medium —
  real version needs the volumetric pass we already ruled out. Skip.

## 6. Recommended order

1. ~~**Gap 1** — directional inscatter~~ — DONE (rimrock, `dirTint`).
2. ~~**Gap 1b** — distance-gradient fog color~~ — DONE (rimrock, `ramp`).
3. **Gap 2** — animated mist density, synced to cloud wind (`WIND_X/Z`).
   Next candidate; noise helpers already in shader.
4. Eyeball rimrock first: tune `fogViewColor` strengths (0.42/0.18) and
   the authored `ramp` stops if the gradient reads wrong — both are
   data/constants, not plumbing.
5. Re-shoot `_tools/tershot/seamcheck.py` terrain→sky seam after any fog
   color change — the h=0 `fogColor` contract (`atmosphericSky.ts:22`)
   must not move. NOTE: `ramp`/`dirTint` currently only affect the
   terrain shader; the sky's h=0 band still uses flat `fog.color`, so a
   strongly-shifted far ramp color could seam at the horizon — check.
6. **Gap 3** (entities) and local fog volumes only if screenshots show
   the need.
