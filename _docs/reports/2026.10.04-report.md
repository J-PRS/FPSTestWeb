## What's genuinely good

- **Authority architecture is real, not aspirational.** `wire.ts` is a model contract: one table entry = validator + rate limit + handler, validation pre-room, handlers inside the tick's command drain. Every damage path funnels through `CombatHandler`/`applyDamage`. The comments document *why* a limit is shaped a certain way (e.g., teleport deliberately unlimited because a drop only desyncs).
- **Shared/ is actually pure.** Zero `Date.now`, `performance.now`, timers, or env reads across 50 files — `Math.random` appears only as injectable defaults (`rollCreatureDrop(r0, r1)`, `botRand` seedable). `sharedPurity.test.ts` pins it.
- **Testing is layered correctly.** ~450 unit tests + 124 scenario files (one staged interaction each) + the hypersoak that caught a real inert-mode bug construction tests couldn't. `sizeWatch` enforces the 900-line ceiling with grandfathered pins — real guardrails, not vibes.
- **Docs are honest.** Changelog entries record *measured* findings ("72m→~15m divergence"), AGENTS files encode the invariants, and the scenario test style (silence brains so scripted shots are the only variable) is disciplined.

## Weak spots

1. **`NetworkManager.ts` (1208 lines, ~66 methods)** — the one true god object left. All the claim/ledger/census logic lives inside it. It's pinned, not burning down. The census blocks (reject/drop/muted/claim) are good diagnostics but the file does transport + claims + telemetry + presence.
2. **Stray files**: `client/src/gunlab copy.ts` (33KB duplicate with a space in the name — dead code that's still typechecked), `.deprecated` adapters in `src/networking/` — these are `.old`-equivalents that survived as real filenames and still compile.
3. **`.git` is 338 MB** — the untracks helped HEAD, but history still carries the ualgrab/zzz blobs. A clone still pulls everything. Only filter-repo fixes that.

5. **Minor**: `vertexAO.ts` lint debt in your WIP (complexity 48/162-line function) — you know about it.

## Verdict

The codebase is in *good* shape — the architecture rules are real because tests enforce them, and the bug history shows a pattern of finding root causes via instrumentation rather than patching symptoms. The main structural debt is `NetworkManager` and the leftover copy/deprecated files; the main systemic debt is git history weight. Nothing I'd call alarming — the risk areas are known and pinned.
