# Reinvented Wheels Audit - 2026-10-01

## Available Libraries

Client deps are deliberately minimal: three.js + three ecosystem
(three-mesh-bvh, three-bvh-csg, three.quarks, postprocessing, manifold-3d,
xatlas), stats.js, sam-js. Server: @webtransport-bun, node-datachannel.
No general-purpose utility libs installed (no zod/lodash/date-fns/fuse) —
correct for a deterministic-sim game where most stdlib code must be
allocation-free and cross-end reproducible anyway.

## Architecture Decisions (Pre-Checked)

`.devin/rules/determinism-perf.md` + `netcode.md` document as intentional:
hand-rolled sims, binary codec, event-sourced netcode, pooling, distance-
tiered sends. Not flag-worthy.

## Real Reinvention (Worth Fixing)

**None found.** Every hand-rolled pattern checked is either
domain-specific, documented intentional, or a <15-line util where a
dependency would be pure cost.

## Justified (Not Reinvention)

### Deterministic PRNG (mulberry32)
- **Files**: `shared/botSkill.ts`, `_tools/sweeps/capperSweep.ts`
- **Why**: ~10 lines of standard public-domain PRNG; determinism is the
  whole point. Two copies is normal practice — the tool version is sweep-
  only, the shared one is sim-critical. A lib adds a dep for nothing.

### Binary wire codec (`shared/wire.ts`)
- DataView pack/unpack with shared quantizers. msgpack/protobuf would
  lose the exact quantization contract and add codegen. Justified.

### String-table validators (`shared/mapSpec.ts`, `shared/perks.ts`)
- `typeof s === 'string' && /^.../` guards + `s in TABLE`. Trivial; zod
  would be massive overkill for 5 type guards.

### Entity state switches (Rakk/Totem/Seeker/Strifer/flags)
- `s.state === 'chase'` style reads against sim-state unions — plain
  state reads, not machines with guards/transitions. XState overkill.

### Settings storage (`core/settings.ts`, `lastRoom.ts`, NetworkManager)
- `localStorage.getItem/setItem` behind a typed settings map; ~10
  call sites total. A wrapper lib gains nothing.

### Manual hex color constants (100+ sites)
- `0x3a4550` material tints are palette constants, not color math. No
  chroma-js equivalent for "the turret is gunmetal".

### Throttle/sampling one-liners
- `x & 15`, `x & 31`, `* 0.5` cooldown fields — two-line counters, each
  domain-specific (log sampling, sizzle pacing, spinout warns).

## Not Reinvention (Stop Worrying)

- CSV in `capperSweep.ts` — self-controlled sweep output format.
- `gunlab.ts` debounce — 5-line setTimeout, plus `gunlab copy.ts`
  duplicated (other agent's scratch copy — not a wheel issue).

## Recommendations

1. **Nothing.** The codebase's hand-rolled surface is deliberately
   hand-rolled — deterministic sims, byte-exact wire formats, and
   allocation-free ticks can't take general-purpose deps. Where a lib
   does exist (three-mesh-bvh for raycasts, xatlas for unwrapping,
   manifold for CSG), it's already adopted.
