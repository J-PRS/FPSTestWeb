# Performance profiling & optimization — report (2026-10-01)

Scope: full client perf arc for KRIBES (Three.js + Bun). Method per standing order: profile first, every cut has a measured before/after. Target hardware: Chromebooks; dev box is i7-13700KF + RTX 3070Ti, 60Hz.

## Profiling infrastructure built

- **`__renderScan(frames)`** (`client/src/game/renderScan.ts`) — in-game staged profiler. Times isolated render stages on the real GPU: `scene` (stale shadow map), `sceneShadow` (forced shadow re-render), `full` (production path), `viewmodel`. Reports cpuMs / calls / tris / gpuMs per stage (gpuMs via `EXT_disjoint_timer_query_webgl2`). Stage deltas isolate pass cost. Console-callable.
- **`__perf`** — per-phase JS timings (player/bots/fx/balls/species/vfx/net/render) + watchdog that dumps `gpu / calls / tris / phase table` to the log on low-fps.
- **Headless GPU probes** (`C:/TEMP/_WEB/headless-test/`): `perfprobe-gpu.js` (real-GPU join, works on locked machine), `renderscan.js`, `castercensus.js` (per-object castShadow/material census), `heapprobe.js` (usedJSHeapSize sawtooth = GC churn).
- Scene audits that rank **triangles per object** — draw calls alone hid the real hotspot (vertex load).

## Findings & fixes (each measured)

| Fix | Before → After |
|---|---|

| Shadow pass gating (caster size + 90m distance, frustum 250→130m, throttle ×2/×3) | +681 calls / +122k tris → **+77 calls**; shadow pass was ~46% of frame |
| Mannequin decimate + LOD1 swap (70m, hysteresis 55m) | 14.6k→6.1k tris base; far bodies →**1.2k tris** |
| Skinned frustum culling (computed bounds; bind-pose bounds were wrong → all 32 rendered) | offscreen remotes now cull |
| Remote shadow casting >80m off; anim mixer 30Hz>60m / 15Hz>120m | shadow pass no longer re-skins all 16 remotes |
| Terrain outer rings half-tessellation; interior buckets region-chunked | ~20k tris cut; far interiors finally frustum-cull |
| Ribbon trails → one merged slot-mesh (240 trails → 1 draw); drawRange caps at live slots | 48k→~7k tris drawn |
| Ball trails → one THREE.Points each (977 Sprites → 17) + emit gated <200m + idle upload skip | removed ~960 draws |

| Sheep-meter LOS 200ms TTL | bot senses allocs/ticks down |

## Where the frame sits now (16 bots, 3070Ti)

- Frame **~7.4ms** (~135fps headroom); every JS phase <1ms except transient death bursts (~2.5–3.8ms, accepted).
- Render ~1.8–3.9ms at ~185 scene calls / +77 shadow calls.
- **Potato tier**: full pipeline ~1.7ms CPU+GPU on the 3070Ti — the chromebook path.
- GPU ladder sheds pixel scale → shadows → clouds → bloom → ambient JS as it degrades (`loopPerf.ts`).

## Remaining items (all builds, not shaves)

1. Octahedral impostors for remotes >150m (kills skinned vert+mixer entirely).
2. Interior texture atlas (~86 buckets → ~10 draws; pays only in dense base views).
3. Wire decode pooling (~object/frame per remote).
4. Known non-perf flags: StateHash DESYNC warnings, camera spinout at map edge, packetLoss counter inflates on slow frames (burst-delivery artifact).
